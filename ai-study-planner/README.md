# 📚 AI Study Planner using Endee (Vector Concept)

An intelligent, beginner-friendly AI Study Planner that generates tailored study schedules and recommendations based on user input. This project demonstrates core semantic search and vector-based retrieval concepts using **Endee**.

---

## 🎯 Features

* **Smart Study Plan Generation:** Automatically creates structured study schedules based on your goals and available time.
* **Semantic Search Recommendations:** Uses vector-like similarity logic to recommend relevant study topics and resources.
* **Simple AI Logic:** Clean, lightweight implementation ideal for learning vector database fundamentals.
* **Beginner-Friendly:** Easy setup with minimal dependencies.

---

## 🧠 Role of Endee Vector Database

[Endee](https://github.com/Kasthuri-001/endee) serves as the core vector database engine for semantic retrieval in this application:

* **Vector Embedding Representation:** Preprocessed study topics and materials are indexed as high-dimensional vectors.
* **Query Match:** User prompts and study preferences are converted into query vectors to measure contextual similarity.
* **Semantic Search:** Returns relevant study tasks based on semantic context rather than exact keyword matches.

---

## 🛠️ Tech Stack & Requirements

* **Language:** Python 3.8+
* **Database Engine:** Endee (Vector Search)
* **Web Interface / App Framework:** Python (`app.py`)
